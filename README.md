# Coffee Sales Dashboard

## 📘 Overview
This project is an interactive **Coffee Sales Dashboard** designed to help track, analyze, and visualize sales data.  
It provides insights into sales trends, revenue performance, product popularity, and customer behavior to support data-driven decisions.

---

## 📊 Key Features
- Sales trend analysis over time  
- Comparison of revenue by product, region, or sales channel  
- Identification of top-selling and underperforming products  
- Visualization using charts, tables, and summary metrics  
- Supports decision-making for inventory, promotions, and marketing  

---

## 🧰 Tools & Technologies
- Microsoft Excel (Formulas, Pivot Tables, Charts, Conditional Formatting)  

---

## 🎯 Purpose
To provide a **data-driven solution** for monitoring coffee sales, identifying patterns, and supporting business strategy.
